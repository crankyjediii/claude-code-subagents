# Changelog

## 1.1.0

- Publish versioned source and per-category plugin archives, a commit-pinned installer, release metadata, and SHA-256 checksums after testing the exact artifacts.
- Include the MIT license in every separately distributed plugin and add release packaging regression tests.
- Add concrete example tasks and reviewed source records for all 170 category definitions.
- Narrow tool access for review, research, planning, and documentation roles; clarify handoffs where execution is unavailable.
- Add routing boundaries for overlapping specialists and distinguish planning from delegated execution.
- Lock installer writes per target and recheck conflicts after downloads to preserve files created during staging.
- Support removal of partially installed categories while preserving manual copies.
- Reject multiline selections and malformed ownership records; clean up pending writes after handled failures.
- Require explicit backed-up adoption of unmanaged files, including identical copies.
- Refresh README artwork, navigation, category browsing, plugin listing assets, and installation and usage guides.
- Expand process checks and publish the source-level audit with its verification limits.

## 1.0.0

- Introduce 170 development agents across ten category plugins, a marketplace, a standalone installer, and a self-contained installer agent.
- Add generated indexes and checksums, ownership-aware removal, backups, and Linux and macOS CI.
